# Projeto Final - MackTheater
## Exercício acadêmico em Java 

- Sistema simples de gerenciamento e venda de ingressos para espetáculos de teatro, desenvolvido em **Java** com foco na prática de **Programação Orientada a Objetos (POO)**.

## Funcionalidades iniciais

    -> Cadastrar um espetáculo;

    -> Cadastrar um cliente;

    -> Vender entradas para um espetáculo.

## Conceitos de programação utilizados

- Programação Orientada a Objetos (POO);
- Herança;
- Polimorfismo;
- Encapsulamento;
- Uso de **ArrayList**;
- Organização de classes e objetos.
